Autoencoder trained on

Each model trained on one kind of mask only.

PSNR is measured on the hidden pixels only, so higher is better. The mean image fill scores about 10 dB, and a model that does no better than that has learned nothing useful for the picture.

The models trained on masks that hid 10 to 70% of the pixels, so results outside that range are less reliable. Try a rectangle with the model trained on random pixels. Averaged over the whole test set it scores about the same as the mean image, and on a single image it can be worse. This is the gap I measured when I trained on one mask type and tested on another.

Each model has 179 thousand parameters, takes a 28 by 28 image plus the mask, and squeezes it through a 64-number bottleneck before rebuilding the image.
